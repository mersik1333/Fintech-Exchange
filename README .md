# 📈 Учебная биржа (FinTech Simulator)

Учебное веб-приложение для симуляции биржевой торговли в режиме реального времени. Проект разработан для демонстрации навыков создания клиент-серверных приложений, работы с фоновыми задачами и динамической визуализации данных.

##  Основные возможности

*   **Стартовый капитал:** Каждому новому пользователю выдается 100 000 ₽ для начала торговли.
*   **Симуляция рынка в реальном времени:** Цены на акции (Газпром, Сбербанк, Apple, Tesla и др.) меняются каждые 2 секунды по алгоритму случайного блуждания с учетом волатильности.
*   **Торговля:** Покупка и продажа активов по текущей рыночной цене с валидацией баланса.
*   **Управление портфелем:** Учет купленных акций, расчет средней цены покупки (Cost Basis) и отображение текущей прибыли/убытка (P/L) по каждой позиции.
*   **Интерактивные графики:**
    *   График цены выбранной акции в реальном времени.
    *   График стоимости инвестиционного портфеля (без учета кэша) с временной шкалой.
*   **История сделок:** Лог последних 15 транзакций с указанием времени и цены исполнения.
*   **Сброс счета:** Возможность начать игру заново одной кнопкой.

##  Технологический стек

**Backend:**
*   C# / .NET 8 (ASP.NET Core Web API)
*   Фоновые службы (`BackgroundService`) для симуляции биржевого стакана
*   Потокобезопасное управление состоянием (In-Memory)

**Frontend:**
*   HTML5 / CSS3 (CSS Grid, Flexbox)
*   Vanilla JavaScript (без тяжелых фреймворков)
*   [Chart.js](https://www.chartjs.org/) — для отрисовки графиков в реальном времени

##  Как запустить проект локально

1. Убедитесь, что у вас установлен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Склонируйте репозиторий или скачайте проект.
3. Откройте терминал в папке с проектом (где находится файл `StockExchange.csproj`).
4. Выполните команду:
   ```bash
   dotnet run
5. Перейдите в браузере по адресу, который появится в консоли (например, https://localhost:49727 или http://localhost:49728).

Примечание: Если браузер выдаст предупреждение о небезопасном сертификате разработчика, нажмите «Дополнительно» -> «Перейти на localhost».

##  Структура проекта
Program.cs — точка входа, настройка эндпоинтов API (/api/state, /api/buy, /api/sell, /api/reset).

Models/Stock.cs — модели данных (Акция, Портфель, Транзакция).

Services/MarketService.cs — ядро приложения (фоновый движок, генерация цен, бизнес-логика покупки/продажи).

wwwroot/index.html — весь клиентский интерфейс (верстка, стили и логика отрисовки на JS).

🔮 Планы по развитию (Roadmap)
Проект является MVP (Minimum Viable Product). Для внедрения в реальный сектор требуются следующие доработки:

□ База данных: Переход с хранения данных в памяти на PostgreSQL и Entity Framework Core (чтобы прогресс сохранялся после перезапуска).
□ Безопасность: Добавление JWT-аутентификации и личных кабинетов.
□ Производительность: Переход с HTTP Polling (опрос раз в секунду) на WebSockets / SignalR для мгновенного получения котировок.
□ Торговля: Добавление лимитных ордеров (отложенных заявок).
□ События: Внедрение новостного движка, влияющего на котировки.
Проект разработан в учебных целях. Приложение не использует реальные денежные средства.
